# Illustration Color Coordination

服の配色を「なんとなく」ではなく手順で決める。対象はイラスト（生成含む）の衣装。
既定のキャラクターは結月ゆかり。別キャラクターなら「1. 設計言語」を差し替える。

## いつ使うか

- 新しい衣装・私服のバリエーションを考える
- 出来上がった絵の配色が「うるさい」「ぼやける」「誰だか分からない」と感じた
- prompt に色語を足す・negative に色 ban を足す前

## 1. 設計言語（結月ゆかり）

公式衣装（通常・凪・A.I.VOICE2・V6・麗）に共通する文法。

| 役割 | 色 | 面積の目安 |
|---|---|---|
| ベース | 黒（インク寄りの黒、青みも茶みも足さない） | 50〜60% |
| サブ | 白（生成り寄りではなく紙の白） | 25〜35% |
| アイデンティティ | 紫（髪の薄紫と、服の濃紫 eggplant は明度を分ける） | 10〜15% |
| 差し色 | 黄緑（ソール・裏地・リボン）または金（麗系） | 5% 以下、1 箇所 |

固定要素: 薄紫の髪・紫の目・黒手袋・黒タイツ。服を変えても脚と手は動かさない。

## 2. 決め方（4 手順）

1. 役割を先に決める。「ベース / サブ / 差し色」を 3 色以内で割り当て、4 色目は入れない。
2. 明度差で分ける。色相の対比より明度の対比が先。黒×白の明度差が絵の骨、紫は中間明度でつなぎ。
   上下の明度は必ず変える（白 T + 黒スカート ○、黒ニット + 黒スカート ×）。
3. 紫は 1 箇所。髪が既に紫なので、服の紫は「髪と別の明度」で 1 箇所だけ（濃紫のベルト、薄紫のカーデなど）。
   2 箇所以上に置くと髪が背景に溶ける。
4. 差し色は末端に。靴底・リボン・ボタン・手首。胴体の中央には置かない。

判定: 「黒・白・紫・差し色 1 つ」に収まっていれば公式寄りとして通す。白黒に飽きた時は次の「色を入れる」へ。

## 2b. 色を入れる（白黒から離れる時）

基準は髪の薄紫。服の色相は髪との関係で選ぶ。

| 関係 | 色 | 印象 | 確認済み |
|---|---|---|---|
| 補色（黄系） | マスタード、からし | 髪が一番映える。橙寄りに出やすい | zo23ah（マスタード×ネイビー good） |
| 隣接（青系） | ネイビー、サックス、くすんだ水色、ティール | 落ち着く。ネイビーは黒の代わりのベースになる。本人評価が一番良い方向 | zv1fwc（生成り×ネイビー good）、wpwhx4（白×ネイビー）、8barea（サックス×ネイビー）、0irpcl（生成り×水色）、lxd8ye（生成り×ティール） |
| 分割補色（緑系） | オリーブ、セージ | 私服らしいが本人評価は bad。緑は靴底など差し色に留める | 6tuibu（白×オリーブ bad）、drhlda（セージ×チャコール bad） |
| 同系の淡色 | ダスティピンク、ラベンダー | 髪と溶けやすい。ピンクは灰みを足せば通る（評価 neutral） | ttizt4（ダスティピンク×チャコール） |

決め方は同じ: 上下で明度を分け、色は 2 つまで（ベース + サブ）、紫は髪に任せて服には置かない。
黒タイツ（または sheer-gloss）が下で締めるので、上下とも有彩色でも崩れない。
明度反転（濃い上 + 淡い下）は同 seed でも構図と丈が変わる（olib5q）ので、比較は「淡い上 + 濃い下」で揃える。
避ける色: 赤・マゼンタ・ネオン（VIVID_BAN で出ない）、茶・ベージュ（sheer-gloss の SHEER_BAN と衝突）。

## 3. 生成 prompt への落とし方

色は「服タグ」ではなく「色語 + 服タグ」で書く。色語が無いとモデルの既定色になる。

| 決めたこと | positive | negative |
|---|---|---|
| ベース黒の服 | `(black skirt:1.25)` のように服ごとに色を付ける | — |
| サブ白の服 | `(white t-shirt:1.35)` | `(off-white:1.1), (cream:1.1)` を足すと紙の白に寄る |
| 紫を 1 箇所 | `(purple belt:1.2)` など 1 語だけ | 他の紫は書かない |
| 差し色 | `(green trim:1.1)` など末端の部位名と一緒に | — |
| 有彩色の服 | `(mustard yellow t-shirt:1.35)`, `(navy blue skirt:1.3)` のように色名 + 服。くすませたい時は `dusty` / `muted` / `sage` を色名に含める | — |
| 入れない色 | 書かない | `(brown:1.2), (beige:1.2)` など色名で ban |

yukari recipe（chagama）の前提:
- `VIVID_BAN` が magenta / bright purple / red / maroon / neon を既に禁止している。赤系の差し色は入らない。
- `standard` costume だけ `GARMENT_BLACK_BAN`（black jacket / black clothes / black hoodie）が入る。standard 上で黒い服を足すと衝突するので、costume を変えるか patch で ban を外す。
- `sheer-gloss` legwear の see-through 語は長いスカートに漏れて透けさせる。丈を伸ばす服では opaque legwear で確認してから戻す。
- 納品の repin で紫は黒に、グレーは紫に寄る（memory: purple-is-one-axis, garment-colour-words）。素の絵で決めた色が納品で動くことを前提に、紫は「少し薄め」で刷る。

## 4. 確認

1. 同 pose・同 seed で色違いを 2〜3 案並べて刷る（chimera の compare リンクで見る）。
2. サムネイル（256px）で見て、髪の紫が服から分離して見えるか。分離しないなら服の紫を減らす。
3. 差し色が 1 箇所に収まっているか。増えていたら negative に色名で ban。
4. 決まった配色は costume として recipe に焼き込み、chimera に observation を残す。

## 参考にした配色の考え方

- 3 色ルール（ベース / サブ / 差し色）と 60-30-10 の面積配分
- 色相の調和より明度の対比を優先する（meodai/skill.color-expert の「hue-first harmony is a weak standalone heuristic」）
- 差し色は面積を小さく、末端に置く（ファッションのコーディネート一般則）
